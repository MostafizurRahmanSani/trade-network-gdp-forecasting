# Do Trade Networks Help Forecast Real GDP Growth?

Code and data for a multi-country benchmark of spatio-temporal graph neural networks, trade-graph controls and conformal prediction intervals for real GDP growth forecasting.

The study asks whether a spatio-temporal graph neural network (STGNN) on yearly bilateral trade graphs forecasts next-year real GDP growth of 182 economies better than models that see only each economy's own history, and how reliable conformal prediction intervals are for such forecasts. It compares 34 forecasting models under one protocol (naive, econometric, machine-learning, recurrent, attention-based and spatio-temporal graph models, plus IMF World Economic Outlook forecasts) and tests whether the trade graph itself carries information with eight graph controls, a graph-density sensitivity analysis, a one-factor ablation, an analysis of the learned weights and a shock-propagation experiment.

## Main findings

- The STGNN reaches a test MAE of 0.0352 log points (2018-2024), 9% below a random walk with drift, but it is statistically tied with random forest, gradient boosting and recurrent networks.
- The IMF October forecast has a lower error than every model on 2018-2023, although not significantly.
- The trade graph does not improve out-of-sample accuracy: the eight graph controls give the same accuracy, the selected STGNN gives almost no weight to the messages from its neighbours, and two graph models that do use their neighbours are not significantly more accurate with the real trade links than with shuffled or random ones.
- Split conformal intervals calibrated on separate years cover 77-80% of outcomes at a nominal 90% level and under-cover mainly in 2020-2022; adaptive and rolling recalibration raise coverage to 84-85% once the shock has been observed.

All reported numbers come from the files in `outputs/`.

## Repository layout

```
src/gdp_stgnn/     models (GNN, GCN, GAT, STGCN, STGAT, DCRNN, Graph WaveNet-style, recurrent), training loops, graph helpers
scripts/           the pipeline, numbered by stage (see scripts/README.md); run_reports.sh regenerates all tables and figures
data/              processed panel and edge files, small external files, data/README.md (sources, licences, how to rebuild)
outputs/           seed-level predictions and results of every run (outputs/runs, outputs/baselines), tables and reports

```

## Setup

Python 3.10 and the versions in `requirements.txt` (PyTorch 2.6 and PyTorch Geometric 2.7, CPU is sufficient):

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
```

## Reproducing the results

The saved runs in `outputs/` contain the predictions of every model, so all tables and figures can be regenerated without training:

```bash
bash scripts/run_reports.sh        # tables, reports and figures (a few minutes; one log per script in logs/)
```

Training from scratch (CPU, one thread per run, about 40 s for an STGNN run; use at most 3-4 parallel workers):

```bash
python scripts/train_neural.py grid --models GRU LSTM RNN BiLSTM Transformer TFT GNN GCN GAT BonnigGAT BonnigGAT_edges STGNN STGCN STGAT DCRNN GWN MTGNN MTGNN_trade --procs 3
```

The remaining stages (baselines, extended tuning, graph controls, ablation, rolling origins, conformal prediction, ...) are listed in `scripts/README.md` in running order. Every neural result is the mean over five seeds (42, 1, 2, 3, 4); runs that already have a result file are skipped, and training is deterministic for a given seed on the same software stack.

## Data

The raw inputs are public: CEPII BACI (HS92, release V202601), the World Bank World Development Indicators and the IMF World Economic Outlook historical forecasts. The processed panel and edge files, the country files and the IMF file are in the repository, so all models and reports run from them. The World Bank extract is included (`data/raw/wdi`). The raw BACI files are about 8 GB, too large for a GitHub repository, so they are not included. They can be downloaded from CEPII at http://www.cepii.fr/CEPII/en/bdd_modele/bdd_modele_item.asp?id=37 (HS92, release V202601) if the processed files are to be rebuilt from scratch. The product-group aggregates (`data/interim`) are rebuilt from them; `data/README.md` describes the sources, their licences and the steps to rebuild the processed files from them.

## Reproducibility details

- **Environment**: Windows 10, Python 3.10.11 and the versions in `requirements.txt`; CPU only (no GPU), one thread per run. Exact reproduction was verified in this environment; other platforms or library versions may differ in the last decimals of the neural runs.
- **Seeds**: every neural result uses the five seeds 42, 1, 2, 3, 4; the seed controls weight initialisation, the mini-batch order of the temporal networks and the randomised graph controls. Training is deterministic for a given seed on the same software stack.
- **Hyper-parameters, parameter counts and run times** of every model: `outputs/additional_tables.md` (table 4 of the paper) and `outputs/tuning_extension.md`.
- **Search procedure**: `scripts/selection.py` and `scripts/README.md`.
- **Checks**: the whole pipeline was rerun from scratch in a clean copy of this repository, using the raw data. The rerun reproduced the processed data files, all 49 baseline prediction files and all 1,270 neural runs (identical predictions and metrics), and every table, report and figure. The results in the paper are therefore reproducible from this repository in the environment above.
